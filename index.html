La Evolución de la Programación

Un recorrido visual por los lenguajes que construyeron el software moderno. Desde las tarjetas perforadas hasta los lenguajes de sistemas actuales.

Por qué importa esta historia

Cada lenguaje nació para resolver un problema concreto de su época: cálculo científico, gestión empresarial, sistemas operativos, web o concurrencia. Entender de dónde vienen te ayuda a elegir mejor cuál usar hoy.

1957

Fortran

Científico

El primer lenguaje de alto nivel ampliamente adoptado. Creado por John Backus en IBM para cálculos numéricos. Permitía escribir fórmulas matemáticas casi como en papel en lugar de ensamblador. Todavía se usa en supercomputación y simulaciones.

1959–1960

COBOL & LISP

Negocios IA

COBOL (Grace Hopper y comité CODASYL) se diseñó para ser legible por gente de negocios. Dominó la banca y los sistemas legacy durante décadas. LISP (John McCarthy) introdujo la programación funcional y el procesamiento de listas; sigue siendo influyente en IA y lenguajes modernos.

1964

BASIC

Educación

Beginner’s All-purpose Symbolic Instruction Code. Diseñado en Dartmouth para que cualquiera pudiera programar. Popularizó la informática personal en los 70 y 80 (Apple, Commodore, MSX…).

1972

C

Sistemas

Dennis Ritchie en Bell Labs. Nació junto a Unix. Ofrece control de bajo nivel con una sintaxis relativamente limpia. Es el abuelo de casi todos los lenguajes de sistemas posteriores (C++, Java, C#, Go, Rust…).

1983–1985

C++ y Objective-C

OOP

Bjarne Stroustrup añadió clases y orientación a objetos a C. Objective-C (usado en NeXT y luego en Apple) trajo mensajería dinámica. Ambos dominaron el desarrollo de aplicaciones de escritorio y sistemas durante años.

1991–1995

Python, Java, JavaScript, PHP, Ruby

Web General

La década de los 90 explotó: Python (Guido van Rossum) por legibilidad; Java (Sun) con “escribe una vez, ejecuta en cualquier sitio”; JavaScript (Brendan Eich) en 10 días para el navegador; PHP y Ruby para el lado servidor. La web se volvió programable.

2009–hoy

Go, Rust, TypeScript, Kotlin, Swift…

Modernos

Go (Google) simplificó la concurrencia. Rust (Mozilla) promete seguridad de memoria sin garbage collector. TypeScript añade tipos a JavaScript. Kotlin y Swift modernizan Android e iOS. El foco ahora es seguridad, rendimiento y productividad del desarrollador.
