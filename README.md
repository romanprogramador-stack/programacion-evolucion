# CodeTimeline — Historia de los Lenguajes de Programación

Sitio web educativo sobre la evolución de los lenguajes de programación. Diseño limpio y profesional, pensado para parecer un recurso real de documentación / historia del software.

**Repo:** https://github.com/romanprogramador-stack/programacion-evolucion

## Características

- Línea de tiempo clara: Fortran → COBOL/LISP → BASIC → C → C++ → Python/Java/JS → Go/Rust/TypeScript…
- Tipografía Inter + JetBrains Mono
- Diseño oscuro moderno (estilo sitios de documentación técnica)
- 100 % frontend (HTML + CSS + JS vanilla)
- Responsive

## Acceso a la sección interactiva

En el pie de página aparece el texto **© 2026**.  
Haz **triple clic** rápido sobre ese año para abrir la sección de herramientas interactivas (juegos).

- No se añade ninguna entrada al historial del navegador
- La URL permanece igual
- Solo se registra la página principal

## Activar GitHub Pages

1. Settings → Pages
2. Source: Deploy from a branch → `main` / root
3. La web quedará en:  
   `https://romanprogramador-stack.github.io/programacion-evolucion/`
